# Primary references

- [OpenAI Agents SDK](https://developers.openai.com/api/docs/guides/agents/sdk): code-first agent orchestration, tools, guardrails, handoffs, and tracing.
- [OpenAI guide to evaluating agent workflows](https://developers.openai.com/api/docs/guides/agent-evals): use traces, graders, datasets, and evaluation runs to find regressions.
- [MCP Python SDK](https://py.sdk.modelcontextprotocol.io/): current Python SDK for MCP servers and clients.
- [MCP first steps](https://py.sdk.modelcontextprotocol.io/get-started/first-steps/): the distinction between hosts, clients, servers, tools, resources, and prompts.

Read the official material alongside the local implementation. The local code is intentionally small so that you can map each concept to one file and one test.
